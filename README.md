# maxweb-media
MAXweb media automation

## Music
Reels in `reels/v3/` include original background music generated by `src/music/synth.py`
(`python3 src/music/synth.py <seconds> out.wav <style>`, style a=modern electronic, b=chill lo-fi, c=energetic house; then loudnorm I=-16).
Rotate styles between consecutive reels. Use v3 files when scheduling (v2 = older single-track versions).
